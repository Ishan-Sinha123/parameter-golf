SCHEDULER REQUIREMENTS (scheduler.py):
1. Main class: Scheduler with a _tick() method called every 5 seconds.
2. _tick() returns a list of Action objects (dataclasses: LaunchScreen, LaunchGate, LaunchPromote, KillExperiment, RejectExperiment, TransitionState). Actions are then executed separately — this makes the scheduler testable without GPUs.
3. Logic per tick: scan queue/ directory for new YAML configs → register via registry. Check running processes for completion → handle results. Schedule pending experiments onto free GPU slots. Run health checks on active experiments.
4. State machine transitions: DEFINED→QUEUED→SCREENING→GATING→PROMOTING→DONE (or REJECTED/FAILED at any stage).
5. Priority ordering: CRITICAL > HIGH > NORMAL > LOW.
6. GPU consolidation: when a promote is queued, drain all screen slots first, then allocate all 8 GPUs.
7. Signal handling: SIGTERM/SIGINT trigger graceful shutdown (finish current tick, kill child processes, close DB).
8. Use threading.Event for the main loop so shutdown is clean.

CLI REQUIREMENTS (autoresearch.py):
1. argparse with subparsers for: daemon, status, promote, kill, kill-all, sweep, export, tree
2. 'daemon' — instantiates Scheduler and runs the loop
3. 'status' — queries registry, prints table of all experiments with key metrics
4. 'promote EXP_ID' — sets experiment status to queue for promotion
5. 'kill EXP_ID' — kills a running experiment
6. 'kill-all' — kills all running experiments and stops daemon
7. 'sweep --template T --param P --values V --parent PARENT' — calls sweep generator from templates/sweep.py
8. 'export results.tsv' — dumps registry to TSV
9. 'tree' — shows experiment lineage tree
